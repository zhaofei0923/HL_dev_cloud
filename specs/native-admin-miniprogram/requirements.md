# 小程序原生管理后台

用户已于 2026-10-15 确认：仅从现有 IF.U 小程序使用管理后台，不采用网页域名或 web-view 方案。现有会员、主理人、聊天和支付流程保留。

1. 管理员登录后，可从“我的 → 管理后台”进入原生总览及主理人、认证、沙龙、套餐、订单管理。
2. 每次管理请求必须在服务端验证当前会员登录会话、活跃状态、authVersion 和现有管理员名单；普通用户、失效账号或伪造身份不得访问。
3. 查询、详情、筛选和分页使用原管理服务；审核、取消和套餐启停保留记录版本、明确确认、幂等请求编号与审计。订单仅查询。
4. 认证证据和材料按原服务核验与审计；换记录、离页、切换账号时清理，不持久缓存或分享。
5. 无需后台网页域名，原生页面通过现有云函数调用；保留原环境配置、依赖和已有业务功能。
6. 交付完整会员小程序的可扫描测试版本，不能用仅包含后台的微搭构建替换现有小程序。

验收分层：本地契约与生命周期测试、完整构建检查、云端只读管理员／越权核验、开发者工具与手机测试。不得用真实业务记录进行无依据的测试审核、取消或套餐启停。
