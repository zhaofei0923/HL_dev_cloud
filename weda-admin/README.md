# HL 微搭运营管理后台

当前六页均已接入受控云函数：运营总览为真实统计，其余五页支持查询、筛选、分页和选中详情；可写业务须在读取详情后填写意见、核对处理摘要并确认提交。套餐价格按用户确认保持固定，仅开放启停。当前应用仍为微搭设计态，云端保存历史及部署证据见 `operations-verification.json`。

| 页面 | 已接入功能 |
| --- | --- |
| 运营总览 | 会员规模、增长与结构；主理人状态和服务覆盖；正式实付、退款、净收款及套餐构成 |
| 主理人审核 | 状态／关键词筛选、分页、选中资料、待审申请通过或拒绝 |
| 会员认证 | 五类认证申请、当前申请详情、明确点选核验信息及加密图片／PDF材料、通过／拒绝／撤销 |
| 沙龙管理 | 状态／关键词筛选、详情与报名统计、审核通过／拒绝、取消未结束活动 |
| 套餐管理 | 固定价格、商品内容和启停配置；退休／旧套餐只读 |
| 支付订单 | 状态／关键词筛选、分页与详情；展示订单快照金额、支付与履约状态及测试标记 |

正式业务数据会在确认提交后修改。认证反馈与内部备注分开，材料仅在当前选择中展示，关闭、换记录、离开页面或登录失效时清除。订单金额不等于核验实收；正式收款仍按驾驶舱统计口径计算。

## 身份与一致性

- 两个函数都以本次 CloudBase 平台身份核验 ACTIVE 内部用户及 administrator 角色，拒绝匿名、外部用户和已撤权账号。请求体内的 UID、角色和凭据不能授权。
- `hlAdminOperations` 使用固定动作白名单。当前调用通过管理员核验后，仅从请求自身的数据属性摘取 `action`、`args`、`requestId`；其余平台传输字段不枚举、不读取、不校验、不转发。业务字段的 getter 和非普通对象仍拒绝；各动作的 `args` 仍执行严格字段白名单、类型和状态校验。
- 微搭 SDK、渲染器和云网关可以在事件外层附加字段，包括 `accessToken`。这些传输字段不能决定身份、权限、服务端环境或业务操作，也不传给业务服务、审计或日志。仅使用本次 `context` 与服务端用户角色核验，取消对完全不使用的外层元数据逐项白名单与长度校验。
- 写操作在事务内核对记录版本、所属账号及当前合法状态；认证额外绑定当前申请 ID 和材料归属。业务变更、审计与幂等回执在同一事务中提交，任何一步失败均回滚。
- 同一确认草稿重试复用操作编号；重复点击不再次处理，版本冲突须重新选择资料。审计保存在 ADMINONLY 集合 `hl_admin_audit_logs`，不记录材料明文、证件信息、核验码或内部备注原文。
- 生命周期通过 `$w.page.handler.operations` 调用与原生按钮相同的已注册处理函数；操作状态保存在这一模块内部的 WeakMap，不在页面对象上增加属性，也不内嵌第二份操作代码。生命周期捕获所属页、处理函数与实例令牌，离页先使请求失效并清除私密资料，旧实例不能清理新实例。生成器保留控制台中的应用描述。
- 查询和重置可在尚未初始化时直接开始只读加载；加载中或提交中禁用重复请求。只读请求不依赖浏览器生成操作编号；写操作仍须取得详情版本、生成安全编号并二次确认。
- 参数校验失败现在会返回服务端固定诊断类别，页面只显示格式合法的诊断编号与 UUID 参考号，不回显令牌、参数值、任意字段名或服务端错误正文。诊断只在管理员核验后生成，不改变权限和业务校验。`ENVELOPE_SHAPE`、`ENVELOPE_ACCESSOR`、`ARGS_PAGE` 等区分业务请求形状、访问器和业务参数；这些类别是定位信息，不能单独证明问题已解决。
- 材料服务只取得认证用途的加密密钥及旧算法派生密钥，不复制 JWT 签名密钥或支付凭据。解密保持原有 AES-GCM 所属会员／类型／材料 ID 绑定，并在返回明文前持久化访问审计。

套餐启停只调整新购商品的配置资格，不修改既有订单、已购权益或支付开关。当前六档固定价格对应微信虚拟商品，后台不提供只改数据库却不生效的调价入口。正式收款开关、退款、补单和手工履约不属于本次开放操作。

## 源文件与维护

- `app.cals.json`：六页原生 CALS；组件固定 `gsd-h5-react@3.31.0`。暖米白／陶土棕沿用小程序品牌，规范见 `design.md`。
- `cockpit-runtime.js`：总览加载与空值处理，全部趋势点保留，日期轴最多显示 8 个短日期。`cockpit-metrics.md` 定义人数与经营收款口径。
- `operations-runtime.js`：五页列表、选择、详情、中文审核选项、确认草稿、敏感材料清理及并发保护。
- `scripts/connect-weda-cockpit.mjs`、`scripts/connect-weda-operations.mjs`：受审状态、事件和资源绑定。
- `scripts/patch-weda-operations-code.mjs`：从最新云备份只替换五页处理函数与生命周期正文，完整保留编辑器元数据、布局、角色和登录配置；不重建页面。
- `scripts/build-weda-admin-design.mjs`：从现有应用重建并自动恢复两类接入，保留六个布局模板和登录配置。
- `scripts/validate-weda-admin-design.mjs`：官方应用 Schema、同版本组件属性、动态表达式及固定动作事件校验。
- `scripts/check-weda-compiler.mjs`、`compiler-contract.json`：以实际编辑器使用的 Babel 7.9.6 和固定摘要检查全部 JavaScript 资源；只编译，不执行应用代码。
- `cloudfunctions/hlAdminCockpit`：只读统计；`cloudfunctions/hlAdminOperations`：只读详情、事务管理动作与选中材料读取。既有 `hlApi/index.js` 保持本轮之前状态。

构建：`node scripts/build-cockpit-function.mjs <esbuild目录> <SDK安装目录> <输出父目录> hlAdminOperations`。SDK 精确版本在函数 `package.json`。独立捆包没有跨函数运行依赖，采用 Nodejs20.19 和官方 SDK ZIP 上传。

`deploy-admin-operations.mjs` 先只读检查既有服务与凭据准备情况；部署只创建／更新指定管理函数及 ADMINONLY 审计集合，不更改其他集合权限。它核对构建哈希、服务所有权与精确环境变量，并验证伪造身份被拒绝。敏感配置只在内存中处理，不写入输出或命令参数。

保存应用使用 `scripts/weda-admin-draft.mjs`，固定既有应用 `app-pq2auygx`，先备份再以 CommitBaseline 保存并完整回读；保存前必须通过实际编辑器编译检查。缺少编译器文件、摘要不符或任一脚本编译失败时拒绝保存。不自动创建重复应用或发布。

编译器文件从 `compiler-contract.json` 记录的腾讯云官方地址单独下载，放入本地输出目录，不能将现代 Babel 替代该版本；第三方编译器文件不提交仓库。运行方式：

```text
node scripts/check-weda-compiler.mjs --cals weda-admin/app.cals.json --babel <官方编译器文件> --stdout
node scripts/weda-admin-draft.mjs <官方MCP-SDK路径> backup
node scripts/weda-admin-draft.mjs <官方MCP-SDK路径> save <官方编译器文件>
node scripts/weda-admin-draft.mjs <官方MCP-SDK路径> verify
```

修复已有云草稿时，先运行保存工具的 `backup`，再将其备份路径与本地 `weda-admin/app.cals.json` 传给代码修补工具。验证后才执行 `save`。备份同一历史可重复读取，但已有备份内容不符时会停止；云端版本有新变化时必须重新基于最新备份修补。

代码修补工具默认仅替换资源正文；加 `--list-feedback` 更新五页的两处列表状态文字，加 `--read-recovery` 更新查询／重置的禁用条件，保留其他样式、事件与布局。“记录数 —”不代表零条数据；若页面上下文或处理函数尚未就绪，会明确提示关闭预览后重新进入，避免把编辑器复用的旧页面误当成空数据。

## 验收边界

用户已确认云端真实运营总览可用。其余操作的本地原生验收使用显著标注的虚构样例，样例接口阻断全部写请求；真实数据核验仅执行 IAM 只读列表及可用详情。业务写入与材料安全由隔离回归和官方 SDK 合同检查验证，没有用真实会员或活动作测试性审核／取消。

真实认证申请目前无样本，尚需首条真实申请的受控业务验收。CloudBase 管理员会话中的全部新操作及发布后访问仍须独立验收。本地原生预览不等于真实云端管理员登录；测试文件、云端备份与原始业务资料不提交。

本次读取恢复按用户要求仅使用代码与云接口。2026-10-14 复现了“页面尚未准备完成”的确定原因：管理脚本内的 `||=` 语法不受微搭实际使用的 Babel 7.9.6 支持，使五个处理模块整体编译失败、无法注册；总览使用单独脚本，因此仍能显示。改为等价的普通赋值后，全部 12 个脚本通过同版本编译。此前使用现代编译器的本地检查漏掉了这一差异，其通过记录不能证明云端编译兼容。

实际编译器、腾讯云模块解析与原生生命周期的隔离验证及云端全文回读分别记录。样例读取仅在本地完成，未对真实会员执行审核，也未变更支付配置。实际编辑器会话、管理员业务链路和 PDF 新窗口仍需用户手动验收。
