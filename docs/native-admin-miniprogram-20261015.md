# 小程序原生管理后台（2026-10-15）

用户已确认管理后台仅在现有 IF.U 小程序使用。入口为“微信登录 → 我的 → 管理后台”，使用小程序原生总览、列表和详情页面，通过现有云函数访问管理服务，不需要后台网页域名或 web-view 业务域名。

## 功能与权限

- 经营总览：7／30／90 天、会员结构、主理人情况、收款及退款趋势。
- 主理人：搜索、状态筛选、详情和审核。
- 会员认证：身份、学历、车辆、房产、资产五类申请，受控核验材料、审核和撤销。
- 沙龙：列表、筛选、详情、审核和取消。
- 套餐：查看固定价格与服务内容，仅支持启用／停用。
- 订单：查看支付、履约、退款状态，仅查询。

首批管理员沿用用户已指定并核验的赵飞业务账号（用户 ID 1）。每次请求均验证签名 ACCESS 会话、当前账号状态、合并状态、authVersion 和服务器管理员名单。微搭内部角色及客户端声明不能授予此权限。

所有管理写操作需重新读取详情版本、明确确认、使用稳定的操作编号，并复用现有事务、审计及幂等服务。版本冲突时刷新详情，要求重新确认。未知结果的重试保留原编号和内容。

认证材料不写入用户缓存或分享地址；临时文件在离页、换号和重新进入时清理。订单页面不执行退款或权益变更。
