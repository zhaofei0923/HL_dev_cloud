## 2. 找到正确的小程序和道具入口

1. 管理员登录微信公众平台，进入本项目小程序，先核对 AppID 为 `wx7e5c0f4d07d2f0f8`。
2. 进入“虚拟支付”。官方文档将其列在 MP 左侧菜单；部分后台版本会将入口归入“支付与交易”，以当前账号实际菜单为准。
3. 已开通虚拟支付的账号进入其商户管理模块，找到基本配置中的“道具管理”。这里是虚拟道具资料入口，普通微信支付商户后台的商品或收款设置不能替代它。
4. 核对当前支付应用 OfferID、环境及商户身份。应用编号必须与该环境下服务器使用的配置一致；不要替换、展示或分享 AppKey、AppSecret 等密钥。
5. 区分开发/沙箱与现网。开发版本中保存道具不等于已经发布到现网；沙箱道具与现网道具的状态要分别核对。

这些入口及开发版本上传、现网发布的关系来自微信当前企业/个体户接入文档。具体添加、保存、提交和发布按钮的名称可能随后台版本变化，按页面对应操作执行。[官方后台与道具管理说明](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment.html)

本项目2026-10-12云端回读的OfferID为 `1450674507`，环境仍为沙箱（`VPAY_ENV=1`），两类正式收费均关闭。此值是服务器配置核验结果，不能替代微信后台七档商品审核或现网发布状态。

## 3. 逐个录入，保存后复核

进入道具管理的添加或上传入口，每次按第1节的一行填写：

- **道具 ID**：复制该行 `productId`，不要用名称代替。
- **名称**：直接使用表中名称，避免加入“保证脱单”“包成功”等承诺。
- **价格**：先看栏位单位，再填对应金额；核对完整套餐总价。
- **备注或商品说明**：使用第4节的文本，写清期限、权益或次数、续费方式。
- **图片**：若当前后台提供图片栏，按该页面要求上传真实的套餐图。可用米白、暖金风格的文字卡，显示名称、期限和牵线次数；不要使用未获授权的会员照片或虚构服务成果。

官方 API 中 `remark` 和 `item_url` 都标为必填；图片 URL 支持 JPG、PNG 等格式。后台页面是否需要额外字段、图尺寸或审核材料，以当前页面要求为准，本文不编造尺寸、比例或其他必填项。[官方上传字段](https://developers.weixin.qq.com/miniprogram/dev/server/API/VirtualPayment/api_start_upload_goods)

保存后重新打开该道具，检查 ID、名称、价格、说明和环境。先查已有道具：同 ID 已存在时核对其实际资料，不要盲目重复上传，也不要临时生成一个新 ID 来绕过错误。

**ID 与价格的固定范围：**七组 ID/价格是本项目当前业务契约，不能单独改微信侧或单独改小程序侧。未来确需调价或换 ID，应先协调服务端目录、订单快照、前端展示和平台发布，再处理存量订单。微信当前公开文档明确限制的是已发布代币的修改，同时说明道具支持编辑保存再发布；本次没有取得“所有已发布道具 ID 或价格永久不可修改”的公开明文。平台是否允许某个已发布道具修改，须以实际后台和平台答复为准，不将代币限制套用到道具。[官方配置说明](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment.html)

## 4. 可直接复制的商品说明

以下是业务说明示例，不是平台已审核文案。若页面限字，优先保留期限、总价对应完整套餐、次数、扣次条件和手动续费；服务规则应在购买页面及协议中完整展示。

### VIP 四档

**VIP周卡**

一次性开通7天VIP会员权益，到期手动续费，不自动扣款。可使用VIP畅聊、微信交换申请、无限划卡、高级筛选、上线提醒、专属客服、会员标识、谁喜欢我、查看来访、隐身访问和专区查看等权益。具体使用条件见购买页面与会员协议。

**VIP月卡**

一次性开通30天VIP会员权益，到期手动续费，不自动扣款。可使用购买页面列明的11项VIP权益，具体使用条件见会员协议。

**VIP季卡**

一次性开通90天VIP会员权益，到期手动续费，不自动扣款。可使用购买页面列明的11项VIP权益，具体使用条件见会员协议。

**VIP年卡**

一次性开通365天VIP会员权益，到期手动续费，不自动扣款。可使用购买页面列明的11项VIP权益，具体使用条件见会员协议。

VIP未到期时续购从原到期时间延长；已经过期时从本次权益确认生效时间开始计算。聊天仍需互相喜欢或正式牵线，交换微信需对方同意；上线提醒需主动订阅，专区仍遵守资料认证和公开授权规则。VIP套餐不包含人工牵线次数。

### 人工牵线三档

**人工牵线1个月**

线上人工牵线服务次数包，有效期30天，共2次。购买前须完善资料并经当前服务主理人确认；付款经系统核实后开始计期。双方同意并在小程序建立正式联系时扣1次，仅推荐、拒绝或建联前撤回不扣次。剩余次数到期不自动延长。不赠送VIP，不自动续费，不保证线下见面或婚恋结果。

**人工牵线3个月**

线上人工牵线服务次数包，有效期90天，共8次。购买前须完善资料并经当前服务主理人确认；付款经系统核实后开始计期。双方同意并在小程序建立正式联系时扣1次，仅推荐、拒绝或建联前撤回不扣次。剩余次数到期不自动延长。不赠送VIP，不自动续费，不保证线下见面或婚恋结果。

**人工牵线6个月**

线上人工牵线服务次数包，有效期180天，共16次。购买前须完善资料并经当前服务主理人确认；付款经系统核实后开始计期。双方同意并在小程序建立正式联系时扣1次，仅推荐、拒绝或建联前撤回不扣次。剩余次数到期不自动延长。不赠送VIP，不自动续费，不保证线下见面或婚恋结果。

这三项的支付发货是向账号发放对应的有效服务次数包，后续每次牵线按双方确认和正式建联履约。不要把发放次数包写成已经完成全部牵线，也不要写成到店、实物或线下见面商品。已建联后的感情发展不自动返次，错误扣次由主理人受理并经审核处理。

微信团队官方运营指南将线上相亲、撮合与互动服务列入虚拟服务范畴；按本项目的在线正式建联定义填写真实服务内容。平台仍会审核实际经营类目和商品，不能靠改名字、把人工服务伪装成实物或加入赠品改变交易性质。该指南作者为微信团队，带官方用户标记，页面最后修改日期为2026-09-17。[官方虚拟支付业务运营指南](https://developers.weixin.qq.com/community/minihome/doc/00002cf077cd4810fee42f4b865c01)

## 5. 发布、审核与同步要分开确认

1. 七行保存复核后，在当前道具管理中执行相应发布操作。若页面出现审核、补充说明或驳回原因，按真实业务提交并保存结果。
2. 分别检查每个 ID 的发布结果，记录环境、完整 ID、名称、价格、审核/发布状态和时间。不要只检查列表总数或看到“保存成功”就结束。
3. 如果使用服务器 API，官方上传与发布接口当前均规定一次请求处理一个道具；七个道具应逐个处理，而不是因为参数是数组就假定可一口气处理七个。API 发布须使用上传开发环境时的原 ID。[官方上传接口](https://developers.weixin.qq.com/miniprogram/dev/server/API/VirtualPayment/api_start_upload_goods)、[官方发布接口](https://developers.weixin.qq.com/miniprogram/dev/server/API/VirtualPayment/api_start_publish_goods)
4. API启动发布成功只表示任务被接受，还要查询任务结果。当前查询接口的总任务 `status=3` 表示成功；逐道具 `publish_status=2` 表示发布成功。失败或部分失败需读具体原因；“ID已存在”也需要回到现有记录核实资料，不能当作本次修改已经生效。[官方发布任务结果](https://developers.weixin.qq.com/miniprogram/dev/server/API/VirtualPayment/api_query_publish_goods)
5. 发布后还会有同步过程。官方客户端文档说明 `-15014` 表示发布尚未生效，通常约10分钟；`-15018` 表示道具或代币审核未通过。等待时长只是提示，等满10分钟不能替代状态确认，也不要反复拉起付款验证同步。[官方客户端错误码](https://developers.weixin.qq.com/miniprogram/dev/api/payment/wx.requestVirtualPayment.html)

平台道具价必须与服务端生成支付参数中的 `goodsPrice` 一致，后者也是分；这正是官方客户端要求的价格校验。七档当前不配置优惠价、活动折扣或另一套 iOS 售价，避免与订单快照不一致。[官方客户端价格字段](https://developers.weixin.qq.com/miniprogram/dev/api/payment/wx.requestVirtualPayment.html)

## 6. iOS 和三档高价另外核对

微信当前文档说明道具可在安卓与iOS使用同一配置；iOS还要求完成虚拟支付开通和小程序简称配置。用户侧要求 iOS 15及以上、微信8.0.68及以上、中国大陆 App Store 账号，最低支付额为1元。后台若还有 Apple 支付相关配置或审核提示，也须按当前账号页面完成；不能因为安卓发布成功就声称iOS已通过。[官方 iOS 条件](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment.html)

本项目当前前端仍统一拦截iOS付款。后台完成iOS开通不会自动解除这一限制；取得平台许可并完成受控验收后，还需由开发人员调整并发布前端入口。

**6980元、19800元、29800元三档的实际高价能力尚未确认，iOS尤其需要单独核验。** 本次检查的官方上传道具与客户端字段只明确单价须为正数、单位为分且与道具配置一致，未见公开的单价最高值或单笔最高值。这里不编造金额上限，也不将“未公布上限”理解为任意金额均可支付。[官方上传价格字段](https://developers.weixin.qq.com/miniprogram/dev/server/API/VirtualPayment/api_start_upload_goods)、[官方客户端参数](https://developers.weixin.qq.com/miniprogram/dev/api/payment/wx.requestVirtualPayment.html)

请平台审核或客服针对这三个完整套餐确认：能否按对应金额发布、Android和iOS是否分别可用、有无该商户/类目的交易限制、Apple渠道是否接受对应价格。可提供第1节表格和第4节真实服务说明，保存书面答复或后台审核证据。若某档不获批准，不自行拆单、降低显示金额、换普通支付或转账规避，先调整业务方案及服务端契约。

## 7. 上架完成后的交接清单

- [ ] 七个 ID 与第1节一致，名称、总价、分单位价格、有效期和次数均已核对。
- [ ] 现网与沙箱分别核对，没有把开发保存当作现网发布。
- [ ] 每个道具的审核、发布及同步结果均有证据；失败或旧 ID 冲突已处理。
- [ ] 三个人工套餐未赠送VIP，未设置自动续费，服务说明没有线下或结果保证。
- [ ] iOS开通与用户设备条件已核对；三档高价的渠道适用情况已取得平台确认。
- [ ] 将已批准的道具资料交给开发人员核对，平台价格与后端订单快照一致。
- [ ] 另行安排获授权的支付闭环验收，确认查单、发放权益/次数包、平台发货、重复推送、取消和退款处理；实际扣款需单独授权。

道具上架和项目收款开关是两件事。目录展示不证明支付已开放；`PAYMENT_INTEGRATION_READY` 与 `MATCHMAKING_PAYMENT_READY` 分别控制新购，本指引不会打开它们。历史订单继续按原支付通道核查，不因新道具上架切换通道或重新扣款。

**交接时请报告真实状态：**“资料已准备”“开发环境已保存”“现网发布成功”“iOS及高价已确认”“支付闭环已验收”分别说明，不能统一写成“七档已可收款”。
