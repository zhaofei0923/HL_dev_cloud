# 原生管理后台加载优化（2026-10-19）

用户反馈进入后台后各页面加载缓慢。本次优化已完成代码、构建、服务端部署和整包扫码预览。手机上的请求次数优化需使用本次新版小程序；原体验包不会自动包含前端改动。

## 变更

- 主理人、认证、沙龙、套餐、订单的列表及详情，取消重复的入口预检，由管理操作接口独立验证当前账号。每次加载、翻页、筛选及详情刷新从两次串行云调用减为一次。
- 总览首次确认权限后即可进入各模块；已打开总览的刷新和日期切换只重取统计，保留模块入口。无权限响应清除数据和入口状态。
- 关联数据按当前页的业务编号读取，详情合并数字和字符串编号查询。小表首次仍并行读取，避免为当前少量数据增加一次网络等待。
- 统计快照内建立临时索引，减少对同一会员、权益表的重复遍历。没有跨请求业务数据缓存。
- 会话隔离、离页清理、过期响应丢弃、认证材料清理、写操作确认、幂等和服务端鉴权继续保留。
